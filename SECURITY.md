# Security

aurral-presence stores a personal Aurral API key in a local `.env` file and sends it only to the Aurral server you configure. Nothing listens on a network port.

If you find a security problem, please report it privately through GitHub's **Report a vulnerability** button on the Security tab rather than in a public issue. Include the version (`aurral-presence --version`), your platform and steps to reproduce.

Fixes go into the latest release only.
